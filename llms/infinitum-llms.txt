# Infinitum

> Infinitum (formerly Infinitum Electric) is an Austin, Texas motor manufacturer, founded in 2016,
> that builds the Aircore EC+ family of air-core printed-circuit-board (PCB) stator electric motors,
> integrated fan and pump systems, Active Front End (AFE) drives, power generation packages and
> off-road traction motors for data centers, commercial and industrial buildings, water treatment,
> agriculture and mobility.

Infinitum does not publish an llms.txt of its own (https://goinfinitum.com/llms.txt returned 404).

## What an agent can and cannot do here

Infinitum is a hardware manufacturer. There is no public developer portal, no OpenAPI, AsyncAPI,
GraphQL SDL or Postman collection, no MCP server, no A2A agent card, and no `/.well-known/`
document on any Infinitum host.

An HTTP/JSON API does exist and Infinitum documents it, but it is gated:

- Motor Selection Tool (MST) API reference: https://mst.goinfinitum.com/docs/api
  Returns HTTP 307 to /sign-in for an anonymous client. An account is required.
- Fan Selection Tool (FST) integration guide (public, and the source for everything below):
  https://support.goinfinitum.com/hc/en-us/articles/52467614888851-Fan-Selection-Tool-FST-External-Integration-with-Third-Party-Applications
  Infinitum states that "access to detailed API documentation and advanced integration
  capabilities requires a valid Non-Disclosure Agreement (NDA)" and "a commercial agreement
  (evaluated on a case-by-case basis)". Endpoint URLs and credentials are issued on request.

Endpoints Infinitum names as available in limited release (names and semantics only - no schemas,
no base URL and no auth scheme are published, so none of this is callable without contacting them):

- Fan selection: required inputs airflow (CFM) and static pressure (in. w.g.); returns matching
  fan systems as JSON.
- Motor selection: returns matching Infinitum motor configurations as JSON.
- Fan chart: returns a base64-encoded JPEG performance chart for a fan configuration.

## The real integration surface

For an integrator, Infinitum's machine interface is on the motor, not on the web:

- BACnet MS/TP (ANSI/ASHRAE/ISO 135): https://support.goinfinitum.com/hc/en-us/articles/52466881309587-BACnet-User-Manual
- Modbus TCP over Ethernet, used by the I-con configuration software
- Analog / digital I/O terminals: https://support.goinfinitum.com/hc/en-us/articles/52466902290451-Analog-Digital-Control-Configuration-and-Wiring
- I-con motor control software (Windows .NET desktop application): https://support.goinfinitum.com/hc/en-us/articles/52466418802707-I-con-Motor-Control-Software
- Aircore EC IoT kit: https://support.goinfinitum.com/hc/en-us/articles/14601854252819-Aircore-EC-IoT-Kit-Quick-Start-Guide
